## Goals

- [ ] Build a UI prototype

### Prototype data

- Start each app session with sample brands, categories, and wardrobe items.
- Keep additions, edits, and deletions in memory while the app is running.
- Restore the sample data when the app restarts.

## Technical Requirements

### Mobile

#### Tech Stack

- Core framework: [Expo](https://expo.dev)
- Supported android version: >= 13
- SDK version: SDK 58 (latest)
- Targeted device: Android device
- Development Tooling: [Expo Go](https://expo.dev/go)

#### Get Started

- [Start with a default project](https://docs.expo.dev/get-started/create-a-project/#start-with-a-default-project)
- Use NPM package manager.
- Use [Expo Skills](https://docs.expo.dev/skills/#install-expo-skills)

#### Color

- Pick yourself a suitable color palette.
- There will only be primary and secondary color.

#### Typography

- Pick yourself a suitable font family.
- Only pick from [Google Fonts](https://fonts.google.com)
- There will only be heading and body.
- Heading and body font family should be different and readable.
